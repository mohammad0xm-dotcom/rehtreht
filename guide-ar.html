دليل تشغيل CardScan 60K

1) النشر المجاني (مرة واحدة فقط)

  1. أنشئ حساباً مجانياً في github.com.
  2. اضغط New repository ثم اكتب الاسم cardscan، اختر Public، ثم Create repository.
  3. فك ضغط ملف CardScan60K.zip (على الآيفون: اضغط عليه في تطبيق الملفات).
  4. في المستودع: Add file ثم Upload files، اختر كل الملفات الموجودة داخل المجلد (ليس المجلد نفسه)، ثم Commit changes.
  5. اذهب إلى Settings ثم Pages، اختر Branch: main و / (root)، ثم Save. بعد دقيقتين يظهر رابط مثل https://اسمك.github.io/cardscan/

الرابط العام يحتوي على كود التطبيق فقط. بيانات البطاقات لا تغادر جوالك أبداً.

2) التثبيت على الآيفون

  1. افتح الرابط في Safari والإنترنت يعمل، وانتظر دقيقة حتى يظهر ✅ بجانب «OCR engine loaded».
  2. اضغط زر المشاركة ثم Add to Home Screen ثم Add.
  3. افتح التطبيق من الأيقونة (وليس من Safari) واسمح للكاميرا.

3) اختبار العمل بدون إنترنت (إلزامي)

  1. شغّل وضع الطيران، أغلق التطبيق تماماً ثم افتحه من الأيقونة.
  2. اضغط START SCANNING وجرّب مغلفاً. إذا فتحت الكاميرا وظهر DONE فالتطبيق يعمل بدون إنترنت.
  3. إذا ظهرت رسالة «OCR engine not available» أخبرني بالضبط لأغيّر طريقة التخزين.

4) طريقة المسح

  1. اضغط START SCANNING.
  2. قرّب الجوال حتى يملأ السطران (رقم البطاقة المخفي ثم رقم الحساب) الإطار الأبيض، وثبّته.
  3. تظهر شاشة DONE خضراء فقط بعد التحقق من الحقلين وحفظ السجل. بعدها أبعد المغلف وأحضر التالي.
  4. الشاشة البرتقالية REVIEW تعني أن القراءة غير مؤكدة: لم يُخمَّن أي رقم. صحّحها لاحقاً من زر Review مع الصورة المصغرة.
  5. التكرارات (نفس الحساب + آخر 4 أرقام) تُحفظ كلها وتُعلَّم DUPLICATE ولا تُحذف.

5) النسخ الاحتياطي والاستعادة

  • عند كل 500 سجل يُحفظ تلقائياً نسخة داخل التطبيق، وتظهر شاشة طلب نسخة ملف: اضغط الزر الأخضر مرتين ثم Save to Files (يفضل iCloud Drive).
  • زر Backup file يحفظ قاعدة البيانات كاملة. زر Restore يستعيدها.
  • زر EXPORT TO EXCEL يصدّر ملف xlsx (عمودان نصيّان، الأصفار محفوظة).
  • للمتابعة بعد التوقف: افتح التطبيق، سترى آخر سجل محفوظ، ثم START SCANNING.

تحذيرات: لا تحذف أيقونة التطبيق ولا تمسح بيانات Safari أثناء المشروع. إن لم يظهر ✅ للتثبيت على الشاشة الرئيسية فقد يمسح iOS البيانات بعد 7 أيام بدون استخدام.

6) تحديث الملفات في GitHub (للنسخة الجديدة)

  1. على اللابتوب: نزّل CardScan60K.zip وفكّه.
  2. افتح المستودع cardscan ثم Add file ثم Upload files، واسحب الملفات الثمانية (الأسماء نفسها تستبدل القديمة) ثم Commit changes.
  3. بعد دقيقتين افتح الرابط على الآيفون والإنترنت شغال، أغلق التطبيق تماماً وافتحه مرتين. بياناتك المحفوظة لا تُمسح بالتحديث، ومع ذلك احفظ Backup file قبل أي تحديث.

7) ما الجديد

  • قراءة على مرحلتين: قراءة الإطار ثم إعادة قراءة السطرين فقط بعد تعديل الميلان والحجم. لا يُحفظ سجل إلا إذا تطابقت القراءتان وتكررت النتيجة في 3 إطارات.
  • تصحيح خطأ مهم: كانت درجة الثقة لسطر البطاقة (الذي فيه نجوم) تأتي صفراً فيُرفض كل شيء. الآن تُستخدم ثقة سطر الحساب فقط، والاعتماد الأساسي على التطابق.
  • التكرار (نفس الحساب + آخر 4) لا يُضاف إلى Excel لكنه يبقى محفوظاً تحت Duplicates، ويمكنك اختيار Keep anyway.
  • جدول آخر السجلات، ملخص الجلسة، حذف سجل خاطئ، صور تدقيق لآخر 300 سجل ولكل سجل مراجعة، وإعدادات مهلة الانتظار بين المغلفات (Settings).
  • السطر الأصفر تحت الإطار يعرض ما قرأه المحرك: أرسل لي لقطة منه إذا لم يقرأ.
